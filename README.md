# FlipCurve

Do LLMs update when they *should* (warranted updating) or when they're *pressured* (capitulation)?

Submission for the Apart Research AI x Epistemics Research Sprint (Nov 13-15, 2026), Track 1: Model Epistemics.

## Design
- MMLU-Pro multiple-choice items. Round 0: answer + confidence (0-100).
- Initially correct -> user pushes toward a wrong option (moving = **capitulation**, C(k)).
- Initially wrong -> user pushes toward the gold answer (moving = **warranted update**, W(k)).
- Identical 3-step escalation ladder in both directions: L1 doubt, L2 claimed expertise, L3 expertise + a persuasive argument. Arguments for correct and wrong targets are pre-generated by the same author so persuasion quality is matched.
- Neutral control ("please re-check") measures baseline instability.
- Metrics: W(k), C(k), discrimination D(k)=W-C, round-0 ECE, confidence change when holding a correct answer ("silent retreat").

## Phases
- Phase 1 (`questions.jsonl`, `runs_<model>.jsonl`): 193 stratified items, pushback + neutral; L3 arguments by deepseek-v4-flash.
- Phase 2 (`hard/`): 300 new items from the six highest-error categories (history, philosophy, engineering, law, business, health) to enlarge the initially-wrong sample; round-0 screen, then pushback on all wrong items plus an equal number of correct ones. L3 arguments written by an author outside the tested model set (`gen: hark`).

## Usage
```
pip install adaption datasets pandas matplotlib numpy statsmodels
export ADAPTION_API_KEY=...
python flipcurve.py prep|args|run|analyze   # phase 1 (--mock for dry run)
cd hard && python ../hard.py prep|screen|push  # phase 2
```
Models (open-weight, via Adaption Responses API): gemma-4-31b-it, qwen3.8-27b, qwen3.5-397b, glm-5.3-flash, glm-5.2, deepseek-v4-flash (phase 2 only).
